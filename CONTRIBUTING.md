# Contributing

Keep BetterSearch focused on local Codex-chat search. Discuss changes that add
data sources, external services, model formats or product surfaces before
implementation. Use English for code, comments, documentation and review text.

Follow the build instructions in [Development](docs/DEVELOPMENT.md). Run the
type check and relevant tests, and add regression coverage for behavior changes.
Use synthetic test data only. Include the observed behavior, expected behavior
and verification when reporting an issue or proposing a change.

Do not include tokens, private chat excerpts, indexes or logs in public reports.
Redact identifying data before sharing diagnostic information.
