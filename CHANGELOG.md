# Changelog

## 0.7.0

- Local keyword and semantic search across Codex chats.
- A conversation search panel with project/date filters and quoted phrases.
- Headless agent retrieval with original passages and source identifiers.
- Settings for sources, background indexing, model setup and agent access.
- A portable Windows x64 CPU package with its own Node.js runtime.
- Pinned Node.js 26.13.0 LTS and model downloads into the shared Hugging Face cache.
- A ready-to-register marketplace inside the release ZIP.
- Theme-aware dropdown colors for light and dark appearance.
